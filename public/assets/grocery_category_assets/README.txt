Grocery Store Category Images
==============================

Separate PNG category images cropped from the generated grocery image collage.

Files:
- all-products.png
- bakery.png
- beverages.png
- dairy-eggs.png
- fruits-vegetables.png
- household.png
- pink-salt.png
- rice-atta-pulses.png

Recommended integration:
1. Extract this folder into your project's existing assets/images/categories directory.
2. Use the local file paths in the category cards.
3. For the All Products card, use a deep maroon background (#6B1838).
4. Use object-fit: cover (or BoxFit.cover) and adjust object-position as needed.

Note: Images are separate crops from a generated composite, so the original panels have
slightly different aspect ratios. Apply a consistent card image frame in the UI.
